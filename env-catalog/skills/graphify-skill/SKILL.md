# Graphify Skill

[Graphify](https://github.com/Graphify-Labs/graphify) builds a **local AST code knowledge graph** (tree-sitter, no LLM for code paths) into `.terrain/graphify-out/`.

## Where the graph lives (this repo)

Terrain standardizes the output to `.terrain/graphify-out/`:

| File | Read when |
|------|-----------|
| `GRAPH_REPORT.md` | Before any architecture/codebase question (god nodes, communities, audit trail) |
| `wiki/index.md` | Navigating per-community articles (generated by `graphify export wiki`) |
| `graph.json` | Programmatic queries only — use the CLI instead of parsing by hand |

## Resolve the Graphify command (read first)

Before answering architecture or codebase questions, read `.terrain/graphify-out/GRAPH_REPORT.md` for god nodes and community structure.

1. Check availability: `graphify --version` (honors `GRAPHIFY_BIN` if set).
2. Not found → ask the user to install it (`uv tool install graphifyy` or `pipx install graphifyy`), then check again.
3. No graph yet (`.terrain/graphify-out/graph.json` missing) → generate it first (below).

## Generate / update

```bash
# First build — AST only, offline, no API key:
GRAPHIFY_OUT=.terrain/graphify-out graphify extract . --code-only

# Incremental refresh (AST-only, no API cost) — run after code changes:
GRAPHIFY_OUT=.terrain/graphify-out graphify update .
```

Rules:

- Run from the **repo root**.
- `update` refuses to overwrite a smaller graph unless `--force` — on a big refactor or graph shrinking after a branch switch, use `--force`.
- Optional semantic pass over docs/images (requires an LLM key of the user's choice): `GRAPHIFY_OUT=.terrain/graphify-out graphify extract .` (omit `--code-only`). Never launch this without asking the user.
- `update` only handles code. If `git status` shows doc/image changes that matter, ask the user (or use `graphify check-update`) whether to re-run the semantic pass.
- After modifying code files in a session, run the incremental update so architecture answers come from the current graph.

## Query the graph

```bash
graphify query "where is authentication handled"
graphify path "ModuleName" "OtherModule"
graphify explain "SymbolName"
graphify affected "SymbolName" --depth 2
graphify god-nodes --top 10
```

Exit codes for queries: 0 answer, 3 ambiguous (ask the user), 4 no match.

## Full wiki export (optional, on request)

```bash
GRAPHIFY_OUT=.terrain/graphify-out graphify export wiki .
```

Writes `wiki/index.md` plus one article per community — agents should navigate `wiki/index.md` instead of reading raw source when the wiki is present.
